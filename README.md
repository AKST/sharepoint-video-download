# sharepoint-video-dl

A signed Safari extension that turns a SharePoint video page into a download.

Open a lecture video, click the toolbar button (or press Cmd+Shift+Y), and the file
downloads. It works by handing the file the player is already streaming to that
site's own `download.aspx`, so nothing is scraped and nothing is bypassed: the
request carries your session and SharePoint applies the permissions it always
applies. A file you cannot watch is a file this cannot download.

Built for OneDrive for Business and SharePoint course libraries, e.g.

```
https://unsw-my.sharepoint.com/personal/<you>/_layouts/15/stream.aspx?id=...%2FECON2112%20Videos%2FLecture%20Video%20-%20September%2023.mov
```

## Install

```sh
npm install
scripts/install.sh
```

Then in Safari: Settings > Extensions, tick **SharePoint Video Downloader**, and
allow it on `sharepoint.com` the first time you click the button.

There is no *Develop > Allow Unsigned Extensions* step. The app is signed with a
real Apple certificate, which is the whole reason the tick survives quitting
Safari — see [docs/signing.md](docs/signing.md).

## Layout

```
src/              TypeScript source and static files
  inject.ts       read ?id=, build the download URL, toast, go
  background.ts   toolbar click -> inject
  manifest.json   MV3; activeTab + scripting, host_permissions on sharepoint.com
  icons/          generated by scripts/make_icons.py
scripts/
  build.sh        tsc + stage out/extension
  test.mjs        runs the compiled inject.js against real URL shapes
  install.sh      convert, build, sign, verify, install
out/              generated; gitignored
```

## Development

```sh
npm run build                   # compile to out/extension
npm run typecheck               # tsc --noEmit
node --test scripts/test.mjs    # test the compiled output
scripts/install.sh              # all of it, then sign and install
```
